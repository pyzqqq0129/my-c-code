# 我的 C 语言学习代码库

欢迎来到我的 C 语言学习仓库！这里记录了我学习 C 语言过程中的所有练习代码和项目。

## 📁 文件说明
*   `Hello.c`：第一个 C 语言程序，打印 "Hello World"。
*   `C语言.cpp`：C 语言基础语法练习。（*注意：建议以后改成 .c 后缀*）

## 🚀 学习目标
1. 掌握 C 语言基础语法（变量、循环、函数）。
2. 理解指针和内存管理。
3. 用 C 语言完成一个控制台小游戏（如贪吃蛇）。

## 🛠️ 如何运行代码
1. 安装 C 语言编译器（如 GCC 或 Visual Studio）。
2. 在终端输入 `gcc 文件名.c -o 输出名` 编译。
3. 运行生成的程序。

## 💡 学习资源
*   参考书籍：《C Programming Language》(K&R)
*   开源项目：GitHub 上的 `the-c-programming-language-2nd-edition-solutions`
